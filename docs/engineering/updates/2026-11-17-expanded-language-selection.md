# Expanded language selection

Settings → Language includes 97 choices across the 95 requested groups. Western Punjabi uses Shahmukhi, Eastern Punjabi uses Gurmukhi, and Kurdish lists Kurmanji and Sorani. Mandarin Chinese uses the existing Simplified Chinese catalog. Central Bikol and Peruvian Quechua are the initial variants.

- The 85 added choices use bundled preview dictionaries with up to 22 common labels. Remaining interface text falls back to the original English. All additions show a Limited translation label in the picker. The existing 12 choices keep their current translation coverage and stored preference codes.
- Search matches the language's name, English name or code. Automatic device language recognizes dialect, script and region where exposed by the browser. Language selection changes the display language and format while keeping the selected country and home currency. Gregorian formatting stays in place for preview languages that would otherwise default to a different calendar.
- Existing legal and financial text still uses its current translation path. Preview dictionaries include common action, navigation and finance labels. They introduce no translation service, external requests, or account storage.
