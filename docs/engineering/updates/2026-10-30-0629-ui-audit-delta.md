- `scripts/audit-ui-controls.js` now scans production JSX with the TypeScript AST for:
  - native buttons, links and forms missing obvious actions;

  - non-native interactive ARIA roles lacking both click and keyboard handlers;
  - tabs missing `aria-selected`;
  - switch/checkbox/radio roles missing checked state and options missing selected state;
  - dialog/alertdialog roles missing an accessible name;
